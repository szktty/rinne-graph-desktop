# AGENTS.md (docs/)

This document provides guidance for AI agents when working with the documentation in the `docs/` directory of the RinneGraph project.

## Directory Overview

The `docs/` directory contains official project documentation, serving as a centralized and organized repository of information for developers, designers, and project managers.

## Documentation Structure

-   **`design/`**: Contains UI/UX specifications, design guidelines, and visual design principles.
-   **`stack/`**: Contains specifications related to the "Stack" data format and structure.
-   **`user-data-directory.md`**: Explains the structure and management of the user data directory.

## Writing Guidelines

When updating or adding documentation:
1.  **Follow Existing Structure**: Adhere to the established Markdown structure and file organization within each subdirectory.
2.  **Accuracy**: Ensure all information is accurate, up-to-date, and consistent with the current state of the project.
3.  **Clarity and Conciseness**: Write clearly and concisely, using appropriate formatting for readability.
4.  **Cross-referencing**: Cross-reference between related documentation sections to improve navigability.
5.  **Consistency**: Maintain consistent terminology and tone across all documentation.

## General Guidance for AI Agents

*   When asked to document a new feature or change, identify the most relevant subdirectory within `docs/` and create the documentation there.
*   If a `README.md` is present in a subdirectory, update it to reflect any new files or sections added.
*   Before creating a new documentation file, check the existing files to avoid duplication.
