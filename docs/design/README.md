# UI Design Guidelines

This document provides design guidelines for achieving a unified UI/UX in RinneGraph.

## 🎯 Important Policy

**Desktop-First Design**: These guidelines are optimized for **desktop applications**. Specifications may differ for mobile.

## 📚 Guideline Structure

### 🏗️ Fundamentals
- **[01. Basic Concepts and Principles](./01-foundations.md)** - Design principles, architecture, core philosophy
- **[02. Design Tokens](./02-design-tokens.md)** - Colors, spacing, typography, borders, etc.

### 🧩 Implementation
- **[03. Component Specifications](./03-components.md)** - Detailed specifications for each UI component
- **[04. Implementation Guide](./04-implementation.md)** - Implementation methods, best practices, common mistakes

### ♿ Specialized Areas
- **[05. Accessibility](./05-accessibility.md)** - Accessibility support, zoom functionality
- **[06. Development Tools](./06-development.md)** - Catalog app, development support tools
- **[07. Button Roles and Sizing](./07-button-roles-and-sizing.md)** - Apple HIG-compliant button roles, size specifications
- **[08. MasterDetailLayout Design Specification](./08-master-detail-layout.md)** - Master-detail pattern borders, resize bar specifications
- **[09. Color Design Guidelines](./09-color-design-guidelines.md)** - Color integration rules, transparency restrictions, theme color application
- **[10. Table View Design Guidelines](./10-table-view-guidelines.md)** - Table view design principles, layout, interaction specifications
- **[13. Panel Layout Design Guidelines](./13-panel-layout-guidelines.md)** - Dialog/panel 3-layer structure, padding specifications, implementation patterns
- **[14. Container-Content Separation Design Principles](./14-container-content-separation.md)** - UI element classification criteria, padding strategy, macOS-like design philosophy
- **[15. Warning/Error Dialog Guidelines](./15-warning-error-dialog-guidelines.md)** - Warning/error dialog design specifications, collapsible error details, copy function
