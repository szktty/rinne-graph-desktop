# Fonde UI Migration: Riverpod Removal Follow-up

Date: 2026-03-26

## Background

The `llms/fonde-ui/llms.txt` was updated to a new version of `fonde_ui` (0.7.0-dev).
The key breaking change stated in the docs:

> `fonde_ui_riverpod.dart` has been removed. All state management is now done via `BuildContext` extensions and controller objects.

However, upon investigation, the actual `fonde-ui-private` source code **still contains Riverpod providers**:
- `lib/fonde_ui_riverpod.dart` still exists and exports Riverpod providers
- `lib/src/riverpod/` directory with sidebar, theme, accessibility providers

This means the **llms.txt describes a future/planned API**, not the current implementation. The current `fonde-ui-private` still uses Riverpod.
