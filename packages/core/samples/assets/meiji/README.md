# 幕末・龍馬関連 人物相関データセット

このディレクトリには、`rinne-graph-desktop`ツールのサンプルとして使用される、幕末、特に坂本龍馬を中心とした人物相関のグラフデータセットが含まれています。

## データ構造

このデータセットは、以下の3つのJSONファイルで構成されています。

*   `schema.json`: データセットのスキーマ定義ファイルです。ノードのラベル（人物、組織など）や、リンクのタイプ（所属、同盟、家族など）が定義されています。
*   `nodes.json`: すべてのノード（エンティティ）のデータが含まれています。人物、組織、出来事、著作などが定義されています。
*   `links.json`: ノード間の関係性を定義するリンクのデータが含まれています。

## データセットの主な特徴

このデータセットでは、複雑な歴史的関係性を表現するために、以下のようなデータモデリングの工夫が施されています。

### 1. 身分 (Status) のノード化
当初、人物の身分は`status`プロパティとして保持されていましたが、複数の身分を持つ人物に対応するため、`Status`という独立したノードに分離されました。人物ノードとは`HAS_STATUS`リンクで結ばれています。

### 2. 家族・婚姻関係 (Family)
血縁および婚姻関係は、`FAMILY`という専用のリンクタイプで統一されています。これにより、「家族」という広い括りでの検索が容易になっています。具体的な続柄（例: "父", "妻", "義父"）は、リンクの`data.relation`プロパティに格納されています。

### 3. 偽名・変名 (Alias)
同一人物が持つ複数の名前（偽名、変名、本名）は、それぞれ独立したノードとして扱われます。これらのノードは`IS_SAME_AS`リンクによって結びつけられ、同一人物であることを示しています。（例: 坂本龍馬 ⇔ 才谷梅太郎）

### 4. 死因 (Death Cause)
この時代の特徴を反映するため、人物ノードには`death_cause`プロパティが追加されています。これにより、「暗殺」「戦死」「病死」「処刑」といった死亡理由をデータとして記録しています。

### 5. 暗殺疑惑 (Assassination Suspicion)
坂本龍馬の暗殺（近江屋事件）のように、犯人が断定されていない歴史的事件については、`SUSPECTED_OF_ASSASSINATION`（暗殺疑惑）という専用のリンクタイプを使用し、容疑者とされる人物との関係性を示しています。

### 6. 著作 (Works)
福沢諭吉の『学問のすゝめ』のように、人物の著作も`Work`というノードタイプで管理されています。著者と著作は`AUTHOR_OF`リンクで結ばれています。

## 利用方法

このデータセットは、`rinne-graph-desktop`ツールで読み込み、グラフデータベースとして可視化・分析することを想定しています。
